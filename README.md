# Manchester United Performance Analysis (2014-2024)

Análisis detallado del rendimiento del Manchester United en la Premier League desde la salida de Sir Alex Ferguson en 2013. Este proyecto identifica patrones de irregularidad, impacto de la inestabilidad en el banquillo y brechas con los campeones.

## 📊 Objetivo
Demostrar cómo la inestabilidad directiva y la falta de consistencia han afectado el rendimiento del Manchester United, cuantificando pérdidas en puntos y eficiencia ofensiva.

## 🛠️ Tecnologías Utilizadas
- **Python**: Lenguaje principal.
- **Pandas**: Manipulación y análisis de datos.
- **Matplotlib**: Visualizaciones estáticas.
- **Jupyter Notebook**: Desarrollo interactivo (opcional).

## 📁 Estructura del Proyecto
```
.
├── analisis_united.py          # Script principal con todo el análisis
├── pl-tables-1993-2024.csv     # Datos de entrada (Premier League tables)
├── analisis_united_2014_2024.csv  # Datos procesados (generado automáticamente)
├── README.md                   # Este archivo
├── requirements.txt            # Dependencias
└── .gitignore                  # Archivos ignorados por Git
```

## 🚀 Instalación y Ejecución
1. Clona el repositorio:
   ```bash
   git clone https://github.com/tu-usuario/manchester-united-analysis.git
   cd manchester-united-analysis
   ```

2. Instala dependencias:
   ```bash
   pip install -r requirements.txt
   ```

3. Ejecuta el análisis:
   ```bash
   python analisis_united.py
   ```

Esto generará gráficos, imprimirá análisis en consola y exportará un CSV para visualizaciones externas.

## 📈 Resultados Clave
- **Brecha con el Campeón**: Promedio de 20.8 puntos por temporada.
- **Impacto de Inestabilidad**: Cambios de entrenador cuestan ~7.4 puntos por año.
- **Eficiencia Máxima**: Louis van Gaal y José Mourinho lideran en puntos por gol.

## 📊 Visualizaciones
- Gráfico de barras: Eficiencia por entrenador.
- Gráfico de líneas: Evolución de la brecha de puntos.
- Scatter plot: Rentabilidad ofensiva (volumen vs eficiencia).

El CSV exportado puede importarse en Tableau, Power BI o cualquier herramienta de BI para dashboards interactivos.
